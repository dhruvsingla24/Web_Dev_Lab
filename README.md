This repository contains all 13 laboratory practicals covering Terminal navigation, Git/GitHub workflows, semantic HTML5, CSS3 design tokens, Flexbox, and CSS Grid layouts.

---

## Practicals Directory

### Module 1: Terminal, Git & GitHub (P1–P4)
- **`01-P1-Terminal-Navigation/`** — Directory creation (`mkdir`), navigation (`cd`, `pwd`), and file listing (`ls`)[cite: 8, 17, 18].
- **`02-P2-Portfolio-Repository/`** — Initializing a local Git repo (`git init`), staging (`git add`), and initial commit (`git commit`)[cite: 8, 17, 19].
- **`03-P3-Feature-Branch-Git-Workflow/`** — Creating `feature/p3-workflow`, committing changes, merging into `main`, and inspecting commit graphs[cite: 8, 17, 22, 23].
- **`04-P4-GitHub-README-and-Version-Tags/`** — Repository documentation (`README.md`) and annotated semantic version tagging (`v1.0.0`)[cite: 8, 17].

### Module 2: HTML & CSS Foundations (P5–P9)[cite: 8]
- **`05-P5-Semantic-Bio-Page/`** — Biography webpage structured with semantic HTML5 tags (`<header>`, `<main>`, `<article>`, `<aside>`, `<footer>`)[cite: 8, 16, 17].
- **`06-P6-Full-Portfolio-Page-Structure-in-Semantic-HTML/`** — Complete personal portfolio layout using semantic sectioning[cite: 8, 15, 17].
- **`07-P7-Design-Tokens-and-Typography-System-in-CSS/`** — Centralized `:root` CSS custom properties and Google Fonts (`Poppins`) typography scale[cite: 8, 14, 17].
- **`08-P8-Sticky-Navbar-and-Card-Overlay-using-CSS-Positioning/`** — `position: sticky` navigation bar and `position: absolute` card status badges[cite: 8, 14, 17].
- **`09-P9-Responsive-Navbar-and-Card-Grid-using-Flexbox/`** — Wrapping Flexbox navigation bar and responsive project card grid[cite: 8, 14, 17].

### Module 3: CSS Layout Systems (P10–P13)[cite: 8]
- **`10-P10-Portfolio-Header-and-Footer-with-Advanced-Flexbox/`** — Space-between alignment, flexible wrapping, and responsive header/footer sections[cite: 8, 14, 17].
- **`11-P11-Newspaper-Style-Three-Column-Layout-with-CSS-Grid/`** — Editorial 3-column layout (`1fr 2fr 1fr`) built with CSS Grid[cite: 8, 13, 17].
- **`12-P12-Portfolio-Projects-Grid-with-Advanced-CSS-Grid/`** — Auto-fitting CSS Grid showcase featuring spanned cards (`grid-column: span 2`)[cite: 8, 12, 17].
- **`13-P13-Choosing-Between-Flexbox-and-Grid-for-a-Shared-Layout/`** — Hybrid dashboard combining 2D CSS Grid (`grid-template-areas`) for macro layout and 1D Flexbox for inner navigation/toolbars[cite: 8, 11, 17].
