This repository contains my laboratory practical work (P1-P13) for **Web Development**. It covers the terminal, Git and GitHub workflows, semantic HTML, CSS design systems, and responsive page layouts using Flexbox and CSS Grid. Each practical lives in its own folder, so you can follow my progress from basic terminal navigation to building complete layouts.

## How to View the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the practical folder you want to view.
4. Open its `index.html` file using Live Server.
5. For CSS-only practicals, link the stylesheet to an HTML file to test the styles.

The HTML and CSS practicals can be opened in a browser. Git command practicals contain the commands and steps to practise in a local repository.
